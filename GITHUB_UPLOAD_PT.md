# Como atualizar o GitHub — Velocity Rivals

Repositório: https://github.com/lukyi124/VelocityRivals-Portfolio

## Antes de começar

Esta pasta é o conteúdo que deve aparecer na **raiz do repositório**. Não publiques apenas o ZIP. Não carregues o ficheiro original do Xbox Game Bar: tem cerca de 140 MB e não está otimizado para o GitHub.

## Atualização pelo navegador

1. Abre o repositório e clica em **Add file → Upload files**.
2. Arrasta **os ficheiros da raiz e as pastas** `screenshots` e `media` de dentro desta pasta extraída. Ao arrastar uma pasta, confirma no ecrã que os caminhos ficam como `screenshots/00-gameplay-hero.jpg` e `media/VelocityRivals_Gameplay_Demo_v01.mp4`.
3. Se a interface do browser não preservar as pastas, abre a pasta correspondente no repositório e usa **Add file → Upload files** lá dentro para carregar os ficheiros.
4. Confirma o resumo de alterações e escolhe **Commit changes**. Se já existir um ficheiro com o mesmo nome, o GitHub deverá permitir a substituição com o commit; em caso de conflito, faz a atualização por pequenas etapas.
5. Volta à página principal e confirma que a imagem principal aparece, que as outras screenshots estão intercaladas com a explicação e que o link do MP4 abre.
6. Copia o endereço do repositório e coloca-o no teu CV e na secção de projetos do portefólio.

## Verificações

- `README.md` na raiz, não dentro de uma subpasta adicional.
- Vídeo editado dentro de `media/`, com nome exatamente igual ao do README.
- `screenshots/` preserva os nomes e inclui os ficheiros da versão anterior e os novos.
- Não carregar `Saved`, `Intermediate`, `DerivedDataCache`, nem packs Fab importáveis para este repositório público.

## Vídeo

- Duração prevista: ~71 segundos, compilado de 9 segmentos reais.
- Formato: MP4 H.264, 1280×720, 30 fps, sem som (gravação original sem áudio audível).
- Sem música adicionada nem outros assets com licenças duvidosas.
- Esta edição mostra condução, setas, paisagem e UI; **não** é um trailer de um jogo completo.
