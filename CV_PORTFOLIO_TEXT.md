**Project:** Velocity Rivals — Off-Road Driving Prototype (Unreal Engine 5)

**CV — short version**

> Developed a playable off-road driving prototype in Unreal Engine 5 using Blueprint Visual Scripting. Designed a custom desert environment using Landscape and Splines, generated rocks and vegetation with PCG, and implemented reusable Niagara-based water/mud interactions. Integrated vehicle HUD elements and route guidance.

**CV — bullets**

- Implemented a free-driving vehicle prototype, including Blueprint input and boost/temperature UI integration.
- Designed drivable off-road terrain, route signage and natural level boundaries with Landscape / Splines.
- Used PCG Surface Sampler, Transform Points and Static Mesh Spawner to populate the environment.
- Added a reusable Niagara splash interaction using Blueprint overlap triggers.
