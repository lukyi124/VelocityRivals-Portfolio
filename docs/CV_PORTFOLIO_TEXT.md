**Velocity Rivals — Unreal Engine 5 Off-Road Driving Prototype**

Developed a playable off-road driving prototype in Unreal Engine 5 using Blueprints. Sculpted a custom desert Landscape and designed routes using Splines, configured procedural vegetation and rock placement with PCG, and implemented a reusable Niagara water/mud interaction. Integrated gameplay controls, directional markers and HUD feedback.

**Technical stack:** Unreal Engine 5, Blueprint Visual Scripting, Landscape, Splines, PCG, Niagara, UMG.

**Scope:** Free-driving technical prototype; no checkpoints, lap system or completed racing mode in v0.1.
